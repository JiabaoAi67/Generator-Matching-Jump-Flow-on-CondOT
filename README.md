# Jumps & Commitments

Results brief from a mechanism-hunting campaign on generative model dynamics:
an analytic jump corrector (CIFAR-10 / ImageNet-32 / F5-TTS speech), how
factorization destroys dimensional correlations, a substitute-or-complement law
of time discretization, and an interactive demo of "continuous commitment
paths" — a family interpolating flow matching ↔ mixture/masked generation.

**Live page:** https://jiabaoai67.github.io/Generator-Matching-Jump-Flow-on-CondOT/

Built on Generator Matching (arXiv 2410.20587), F5-TTS, EPSS, GMFlow.
All numbers trace to internal reports; evidence grades labeled inline
(including one preregistered NO_GO)
